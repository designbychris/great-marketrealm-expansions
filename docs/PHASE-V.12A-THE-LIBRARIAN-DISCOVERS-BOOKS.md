# Phase V.12A — The Librarian Discovers Books

V.12A turns the Reading Room's Almanac listings into a collection rather than a dashboard.

## Contract

- Almanacs remain canonical Catalogue/Library objects. This phase changes presentation only.
- The 3:2 Almanac Cover Standard remains intact; covers are shown face-out like landscape sourcebooks or deluxe campaign folios.
- Your Library remains the active shelf. Browse remains the complete installed collection.
- Cover art is now the primary discovery surface; metadata and Keeper controls remain available underneath without being overlaid on the art.
- Books link directly to the existing Almanac detail route. No activation or publication meaning moves into the cover UI.
- Missing artwork receives a deliberate Great MarketRealm Almanac cover rather than an empty hole.
- The catalogue metrics are compressed into a Librarian's Catalogue strip so the sourcebooks remain the visual priority.
- Shelf depth, page edges and hover lift are decorative only. Reduced-motion and forced-colour modes remove those effects without hiding information.

## Visual model

The Reading Room is the room. V.12A changes what is sitting inside it:

1. a restrained catalogue strip;
2. face-out 3:2 sourcebook volumes;
3. timber display shelves with brass labels;
4. compact catalogue plates below each cover;
5. existing detail, correction, activation and compatibility controls retained as functional metadata.

This keeps the Great MarketRealm visual language while making a growing collection of Almanacs immediately legible as books rather than generic web cards.

# Almanac Cover Standard

Phase V.10B standardises Reading Room cover artwork so an Almanac can use one canonical cover across Your Library, Browse, and future consumers.

## Canonical presentation

- Preferred aspect ratio: **3:2 landscape**.
- Recommended working size: **1800 × 1200 px** (or any larger 3:2 equivalent).
- Keep titles, logos, faces, and other essential details away from the extreme edges.
- Reading Room cards use `object-fit: cover`; non-3:2 legacy art remains usable but may crop.
- The same pack-relative artwork path remains canonical; this phase does not create a second image source.

## Shelf rule

**Your Library = active Almanacs. Browse = every available installed Almanac.**

An inactive expansion remains canonical and available in Browse, but leaves the user's active Library shelf until explicitly activated again.

## Review Desk bulk rule

Bulk review changes review decisions only. It does not publish, install, activate, or mutate the Catalogue. Bulk acceptance only accepts selected staged definitions that are already valid; unsafe records remain pending for individual Keeper attention. Bulk rejection records a rejection for selected pending records.
